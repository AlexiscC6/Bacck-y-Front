# Proyecto To-Do List

## Requisitos
- Node.js
- MySQL

## Instrucciones de ejecución

### 1. Servidor (Backend)
1. Abrir la terminal e ingresar a la carpeta:
   `cd backend`
2. Instalar dependencias:
   `npm install`
3. Importar la base de datos `schem.sql` en MySQL.
4. Iniciar el servidor:
   `node server.js`

### 2. Interfaz (Frontend)
1. Abrir el archivo `frontend/index.html` en el navegador.
